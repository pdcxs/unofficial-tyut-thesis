# unofficial-tyut-thesis

非官方太原理工大学本科毕业论文 typst 模板

本项目在 [南京大学学位论文 modern-nju-thesis](https://github.com/nju-lug/modern-nju-thesis) 的基础上进行了修改，在此表示感谢。

只适用于本科生，研究生与博士生请勿使用。

如果需要在在线版APP中使用此模板，需要将 `fonts` 目录中的所有字体上传至项目目录中。

## 开始使用

建议直接通过模板生成 Github 仓库，这样可以及时使用最新的模板。使用方法参见：<https://github.com/pdcxs/tyut-thesis-template>

也可以通过[官方APP](typsthttps://typst.app/)，通过从模板新建来找到本模板，不过官方仓库更新有大约10天的延迟。而且需要将本仓库的 `fonts` 文件夹中的所有字体上传到官方程序新建项目的文件当中（任意位置均可）。
